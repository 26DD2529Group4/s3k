# Exercise 1 

This is an exercise to get familiar with s3k.

The exercise consists of the following tasks
* Implement two small programs (A and B)
* A boots B and sets up executable/readable code memory and writable/readable data/stack memory
* A sets up a socket with B
* A can receive a request to change B code memory as writable/executable/readable
* B overwrite its own code (and probably crashes)
